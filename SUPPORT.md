# Support

## Where to ask what

- Bug reports: open a GitHub issue with reproducible steps
- Feature requests: open a GitHub issue describing the use case
- Security concerns: follow [SECURITY.md](SECURITY.md)
- Local setup problems: open a GitHub issue and include environment details

## Helpful details to include

When asking for help, please include:

- Your OS and Node.js version
- Whether you are running from source or a packaged install
- Which agent CLI you are using: Claude, Codex, or Gemini
- Relevant logs, screenshots, or stack traces
- Exact reproduction steps

## Support boundaries

This repository currently provides community support on a best-effort basis.
There is no SLA for issue responses.
